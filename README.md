## 手机性能优化（2026-11-14，mobile1）

目录及庆典左上角可选择“自动 / 流畅 / 丰富”，选择保存在当前浏览器。自动档根据屏幕和庆典绘制负担调整效果；流畅档进一步减少粒子、发光和非必要装饰动画。二维场景、十二幕互动、烟花形状及庆典顺序保留。手机觉得卡时可直接切“流畅”，无需重新打开礼物。

烟花与纸屑按颜色分组绘制，星空缓存为静态画布，限制瞬时粒子数；庆典覆盖时停止环境 Canvas，隐藏并暂停背后的场景。时间进度使用实际经过时间，暂停及切到后台不计入。手机默认转场只显示一幕插画，转场期间暂停装饰动作，减少全屏滤镜。

新增 performance.js / performance.css。全部资源仍在发布包内；没有新增统计、外部脚本或上传。性能验证来自桌面浏览器的手机尺寸模拟，未在实体手机测试，实际效果仍受设备与浏览器影响。
